## 卡包导入与管理后台更新

- 新增卡包管理后台，可集中查看本地所有卡包批次，支持搜索、筛选、排序、分页、批量启用/停用、批量删除和详情查看。
- 导入结果现在会区分“导入失败”“导入成功，但有以下提示”和“导入成功”，并保留批次 ID、来源文件、健康提示等信息，方便排查问题。
- 卡包导入兼容性进一步提升：当导入包缺少职业、领域、社群或变体等预声明时，系统会根据卡牌内容自动补齐，并尽量继续完成导入。
- 修复了前置卡包已经启用时，依赖定义仍被误标为“异常”的问题。若所需职业、领域或变体已经由系统内置卡包或已启用卡包提供，将不再重复报错。
- 管理后台现在也会更清晰地区分“已启用”“未启用”“异常”三种状态，方便整理批次、核对来源并处理旧卡包。

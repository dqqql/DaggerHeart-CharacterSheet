## 1. 统计口径

- 本文档仅基于以下两份已落档中文审查报告整理当前可确认进度：
  - [《面向性能的代码审查报告》](./performance-oriented-code-review-report-zh.md)

- “已完成”只表示审查、归档或清单整理已经完成，不表示相关代码问题已经修复。
- “待处理”表示报告中已经识别并提出了后续动作，但在当前已落档材料中还没有可确认的实现、验证或关闭记录。
- 当前仓库存在并行改动；本文件不对尚未复审的并行改动做完成认定，状态以两份已落档报告中能够确认的信息为准。
